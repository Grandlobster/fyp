╔══════════════════════════════════════════════════════════════════════════════════╗
║                           DATA FLOW SEQUENCE                                     ║
╚══════════════════════════════════════════════════════════════════════════════════╝

1. USER ACTION
   └→ User opens dashboard

2. FRONTEND (App.tsx)
   └→ useEffect() calls DataService.getPatient(mrn)

3. DATA SERVICE (data.service.ts)
   └→ Checks VITE_USE_MOCK_DATA environment variable
       ├→ If true:  Return MockDataService.getPatient(mrn)  [Development]
       └→ If false: Call API.Patient.getPatient(mrn)       [Production]

4. API SERVICE (api.service.ts)
   └→ HTTP GET request to http://localhost:8000/api/v1/patients/{mrn}
       ├→ Sets headers (Content-Type, Authorization)
       ├→ Sets timeout (10 seconds)
       └→ Returns typed response Promise<Patient>

5. BACKEND (backend_example.py)
   └→ FastAPI endpoint @app.get("/api/v1/patients/{mrn}")
       ├→ CORS check (allowed origin?)
       ├→ Pydantic validation
       ├→ Query database or mock data
       └→ Return ApiResponse<Patient>

6. DATABASE (PostgreSQL)
   └→ SELECT * FROM patients WHERE mrn = 'MRN-2024-789456'
       └→ Returns row via SQLAlchemy ORM

7. RESPONSE FLOW
   └→ Backend formats response → Frontend receives JSON → DataService transforms
       → App.tsx updates state → Components re-render with patient data
